# RailOptix AI — SIH25022 Demo

A responsive, interactive front-end prototype for **Maximizing Section Throughput Using AI-Powered Precise Train Traffic Control**.

## Run locally
1. Download and unzip this folder.
2. Open `index.html` in Chrome, Edge, or Firefox.

No build step or dependencies are required.

## Publish a public demo link with GitHub Pages
1. Create a new GitHub repository named `railoptix-ai-demo` (or another available name).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. GitHub Pages will show your public URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/railoptix-ai-demo/`

Replace `YOUR-GITHUB-USERNAME` with your account name and use the exact URL shown by GitHub Pages in your submission form.

## Important demo limitations
- This is a front-end demonstration with illustrative sample train, ETA, throughput, and alert data.
- It is not connected to Indian Railways or any live railway feed.
- The AI recommendations are explanatory examples; buttons do not issue real train-control commands.
- Do not describe the prototype as a live operational system unless you connect and validate real backend services.
